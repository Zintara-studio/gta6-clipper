# Background music

Put `.mp3` / `.m4a` / `.wav` tracks in this folder. Each clip gets one at random, turned down and ducked under speech.

**Only use tracks you can legally use on YouTube.** Copyrighted songs (including most "brainrot" phonk/TikTok sounds)
trigger Content ID: the claimant takes the Short's revenue, or the clip gets muted/blocked.

Safe sources:
- **YouTube Audio Library**: studio.youtube.com → Audio library. Filter by "No attribution required".
- Tracks you bought with a licence that covers YouTube.

This folder is git-ignored, so everyone picks their own music. That also keeps channels from sounding identical.
